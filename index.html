Нажимая кнопку Start в Telegram-боте и продолжая пользоваться сервисом, пользователь принимает опубликованные Правила пользования и Политику обработки данных.

Правила пользования сервисом

Версия 2026-09-02, редакция от 02.09.2026

1. Что делает сервис

Сервис «Пишу» — ИИ-помощник для подготовки текстов, черновиков, планов, справочных и практических материалов через Telegram-бота @PishuAIBot.

Результат создаётся автоматически с применением искусственного интеллекта. Он предоставляется как материал для самостоятельной доработки и проверки, а не как гарантированно готовое решение для сдачи, публикации или принятия третьими лицами.

2. Ответственное использование

Пользователь самостоятельно проверяет факты, расчёты, ссылки, цитаты, оформление и соответствие результата своей задаче до использования. Пользователь сам принимает решения о том, как применять полученный текст, и несёт ответственность за такое применение.

Сервис не гарантирует отсутствие ошибок, уникальность, прохождение проверок на заимствования, соответствие требованиям третьих лиц, получение оценки, публикацию или иной конкретный результат.

Нельзя использовать сервис для нарушения закона, обмана, выдачи чужого текста за результат самостоятельной работы без требуемого раскрытия, распространения вредоносного содержимого или нарушения прав третьих лиц.

3. Данные, которые не следует отправлять

Не отправляйте в бот паспортные, банковские, медицинские, биометрические данные, пароли, коды доступа и иные чувствительные сведения. Не передавайте персональные данные третьих лиц без законного основания.

Пользователь отвечает за содержание сообщений и файлов, которые отправляет сервису. Сервис может отклонить запрос, если он нарушает правила безопасности или законодательство.

4. Оплата, сроки и поддержка

Доступные функции, цена и условия бесплатного использования показываются в интерфейсе до подтверждения заказа. Статусы и сроки подготовки материалов являются ориентировочными и могут изменяться при технических сбоях или высокой нагрузке.

Вопросы по оплате, техническим ошибкам и возвратам направляйте в поддержку: support.pishu@gmail.com, указав Telegram ID и номер заказа. Права пользователя, предусмотренные законом, сохраняются.

5. Принятие правил и изменения

Нажимая кнопку Start в Telegram-боте и продолжая пользоваться сервисом, пользователь подтверждает, что ознакомился и согласен с этими Правилами и Политикой обработки данных. Дата и версия документов фиксируются технически.

Сервис может обновлять документы. При изменении версии для продолжения использования потребуется повторно нажать Start и принять новую редакцию.

Политика обработки данных

Версия 2026-09-02.1, редакция от 02.09.2026

1. Оператор и назначение

Оператор сервиса «Пишу»: Подлявский Дмитрий Алексеевич, плательщик налога на профессиональный доход. Для вопросов о данных и работе сервиса: support.pishu@gmail.com.

Политика описывает обработку данных при использовании Telegram-бота @PishuAIBot.

2. Какие данные хранятся

В базе данных сервиса хранятся Telegram ID пользователя и тексты, относящиеся к проекту: тема, параметры, пожелания, сообщения в поддержку и созданные материалы. Имя, фамилия, username и язык из профиля Telegram сервис не сохраняет.

Дополнительно система хранит только технические отметки, необходимые для работы сервиса: состояние заказа, время операций, сведения об оплате, доступные лимиты и дату с версией принятых документов.

Не отправляйте чувствительные данные. Если пользователь сам включит личные сведения в текст проекта или сообщение, такой текст может быть сохранён как часть проекта до его удаления.

3. Для чего используются данные

Telegram ID нужен, чтобы доставить результат и ответы поддержки в нужный чат. Тексты проекта нужны для подготовки, редактирования и выдачи материалов. Технические записи нужны для оплаты, лимитов, защиты от ошибок и работы поддержки.

3.1. Сервисы, участвующие в работе бота

Telegram используется для работы бота, получения сообщений и доставки результата в чат. Через Telegram передаются Telegram ID и сообщения, которые пользователь отправляет боту.

DeepSeek используется как ИИ-провайдер для подготовки текста. Для выполнения запроса сервис передаёт DeepSeek содержание проекта: тему, параметры, требования и текстовые материалы пользователя. Telegram ID специально в запросы к DeepSeek не передаётся. Не включайте в проект паспортные, банковские, медицинские и иные чувствительные данные.

ЮKassa используется для приёма платежей. При создании платежа передаются номер заказа, сумма и описание платежа. Данные банковской карты пользователь вводит на защищённой странице ЮKassa; сервис «Пишу» не получает и не хранит реквизиты банковских карт.

Указанные сервисы обрабатывают данные по собственным правилам. Они используются только в объёме, необходимом для работы Telegram-бота, подготовки текста и проведения оплаты.

4. Срок хранения и удаление

Данные хранятся, пока пользователь пользуется сервисом, либо до обращения об удалении, если более длительное хранение не требуется законом. Для удаления направьте запрос на support.pishu@gmail.com и укажите Telegram ID.

При удалении удаляются тексты проектов, файлы и сообщения поддержки. Техническая отметка, необходимая для соблюдения требований закона или предотвращения повторного использования бесплатного доступа, может храниться в минимальном объёме, предусмотренном законом.

Резервные копии заменяются при следующем успешном резервном копировании. До замены резервная копия может содержать удалённые данные, но не используется для новых целей.

5. Защита и обновление политики

Сервис применяет организационные и технические меры для защиты данных от несанкционированного доступа, изменения, утраты и распространения. Пользователь вправе запросить сведения об обработке данных по адресу support.pishu@gmail.com.

Новая версия политики публикуется на этой странице. Нажатие Start после публикации новой версии подтверждает её принятие.
